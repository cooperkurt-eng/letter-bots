HOW IT WORKS

  • The game says a letter name and the player finds it. The letter isn't shown on screen, so they practice knowing letters by name instead of matching shapes.
  • Only the first tap on each question counts. Missed letters come back more often.
  • After two wrong taps, the right robot glows so every question still ends with a win.
  • A letter counts as mastered once first-try right answers outnumber misses by at least 4, with 75% accuracy or better.
  • Practice starts with the letters in the player's name, then common letters like S, A, T, M, P. The name and progress are saved on this device only.
